# CandleBlend

Free candle fragrance load calculator: enter vessel volume, pick your wax and load %, and get exact wax and fragrance-oil weights per candle and per batch.

## Features
- Vessel fill volume converts to wax weight via per-wax density, in ml or fluid ounces
- Fragrance load slider with per-wax maximum-load warnings and wax-basis vs total-basis toggle
- Batch scaling by jar count with drift-free math and a cure/pour-temp reference
